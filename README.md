# linefollower
A line follower robot with Raspberry Pi Pico

# Ομάδα 7 Ε1
Το έργο μας έχει σαν στόχο
1) Αυτόνομη Πλοήγηση: Ακριβής και ομαλή παρακολούθηση της μαύρης γραμμής στην πίστα, χρησιμοποιώντας αλγόριθμο PID (Proportional-Derivative) για τον βέλτιστο έλεγχο των στροφών.
2) Λειτουργία Επαναφοράς: Ικανότητα του ρομπότ να "θυμάται" την τελευταία έγκυρη κατεύθυνση, ώστε να στρίβει αυτόματα προς τη σωστή πλευρά και να ξαναβρίσκει τη γραμμή αν βγει εκτός πίστας.
3) Αυτόματος Τερματισμός: Έγκαιρη αναγνώριση της γραμμής τερματισμού και ακαριαία ακινητοποίηση του ρομπότ για την ολοκλήρωση της διαδρομής.
4) Βελτιστοποίηση Ταχύτητας: Επίτευξη της μέγιστης δυνατής ταχύτητας κίνησης (base_speed) στην ευθεία, χωρίς να χάνεται η σταθερότητα του ρομπότ στις κλειστές στροφές.

Τα υλικά που χρειάζονται:
1) Πλακέτα Raspberry Pi Pico W with Headers
2) Maker Driver: Simplifying H-Bridge Motor Driver to Beginner
3) N20 gear motor 1000 rpm
4) DC-DC Boost Buck Adjustable Step Up and Step Down Automatic Converter XL6009 Module
5) Waveshare Ανιχνευτής Ακολουθίας Γραμμής - 5-Channels
6) 44x19mm D axis rubber tire (x2)
7) Mini ball caster for Smart Car
8) 40P 10cm wire female to male
9) 40P 10cm wire female to female
10) Μπαταρία Λιθίου των 7,2 V και 500 mAh
11) Chassis
